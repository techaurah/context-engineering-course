# Resources

Start with the primary sources the course is built on; all
checked 2026-11-06 and cited with dates in
[RESEARCH.md](../RESEARCH.md).

- Anthropic, "Effective context engineering for AI agents"
  (engineering blog, 29 September 2025): the canonical
  definition and the operating principle this course measures.
- LangChain, "Context Engineering for Agents" (blog, July
  2025): write, select, compress, isolate.
- Liu et al., "Lost in the Middle: How Language Models Use Long
  Contexts" (TACL 2024): the position curve of Lessons 05, 18,
  and 19.
- Chroma, "Context Rot" (research report, July 2025): the
  length degradation of Lesson 04, measured on 18 real models.
- Anthropic's multi-agent research write-up (June 2025) and
  advanced tool use post (November 2025): isolation economics
  (Lesson 23) and tool definition costs (Lesson 24).

Companion TechAurah courses: Agentic AI for Beginners (build
agents), Agentic RAG (retrieval from scratch), Testing AI
Agents (the gates discipline this capstone borrows), Build MCP
Servers (tool surfaces from the other side).

See [glossary.md](glossary.md) for the course's definitions,
kept deliberately short: this course is reference shaped, and
the glossary is its smallest reference page.
