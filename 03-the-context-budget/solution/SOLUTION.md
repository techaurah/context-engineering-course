# Solution: The context budget: accounting for a finite window

History breaks first under both changes (at turn 16 with a 400 allowance), because it is the only component that grows every turn while the others sit at fixed allowances. Doubling retrieval raises the total but does not move history's breaking turn at all. Policing priority follows growth, not size: the component that grows unbounded (history, then tool results) needs the policy; the fixed components need a one time audit (Lessons 06 and 24).
