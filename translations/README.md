# Translations

The course is written in English. Translations are welcome and
are kept in this folder, one subfolder per language code, as
complete lesson-for-lesson copies.

A translation must keep every number identical to the English
original: the numbers are outputs of the same code on the same
fixtures, in every language. If a translated lesson's numbers
differ, the translation is wrong, not the code. Translate the
prose; never translate code identifiers, fact ids, or gate
values.
