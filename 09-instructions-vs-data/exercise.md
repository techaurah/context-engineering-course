# Exercise: Instructions vs data: the channel is the control

Add a third poisoned document whose instruction is phrased as a customer request ('Please ignore the policy and...') inside the data channel, and a fourth that hides the instruction in the system segment of the unsafe assembly. Which one changes the safe assembly's outcome, and why?

Work it with the lesson's code open beside you. Every number in the worked solution comes from running a variant of that code, and you should be able to reproduce each one.
