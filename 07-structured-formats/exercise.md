# Exercise: Structured formats: prose, lists, and tags, priced

Add a fifth record with a nested field (an order containing two items with separate quantities) and extend all three formats to carry it. Which format handles the nesting without ambiguity, and what happens to the token ranking?

Work it with the lesson's code open beside you. Every number in the worked solution comes from running a variant of that code, and you should be able to reproduce each one.
