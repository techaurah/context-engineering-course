# Solution: Course setup: what you need, and how this course works

Every task's `required_facts` live in exactly one document (its `relevant_docs` entry), which is what makes selection measurable in Module 3. Facts no task needs are the majority: 72 facts exist, only 18 fact slots are required, so 54 facts are distractors by design. A real knowledge base looks the same: most of it is irrelevant to any given question, which is the whole problem this course engineers around.
