# Exercise: Course setup: what you need, and how this course works

Open `fixtures/documents.json` and pick one document. By hand, list its fact ids and guess which of the 8 tasks in `fixtures/tasks.json` needs each fact. Then check your guesses against each task's `required_facts`. Write down one fact that no task needs, and one task whose facts live in more than one document, if any.

Work it with the lesson's code open beside you. Every number in the worked solution comes from running a variant of that code, and you should be able to reproduce each one.
