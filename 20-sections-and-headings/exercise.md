# Exercise: Sections and headings: layout as a retrieval surface

Rename the headings to vague marketing labels ('Good to know', 'Useful bits', 'More details') and rerun. What happens to the headed reader, and what does that prove about where the value lived?

Work it with the lesson's code open beside you. Every number in the worked solution comes from running a variant of that code, and you should be able to reproduce each one.
