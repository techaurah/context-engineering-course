# Solution: Sections and headings: layout as a retrieval surface

Accuracy collapses toward the flat result: the reader can no longer match questions to sections, so the headings are decoration. The value was never the visual structure; it was the matchable vocabulary at the section boundary. This is the same lesson as the JIT index (Lesson 12) at a smaller scale: every navigation surface is only as good as the words it shares with the questions.
