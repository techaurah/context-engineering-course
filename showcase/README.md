# Showcase

Pipelines built by learners following this course, gated
against the Lesson 29 spec or a documented spec of their own.

To be listed: open a pull request adding your repository, its
gate table (including any failed first runs, which are welcome
here and expected), and one paragraph on what the measurements
changed in your assembly. Entries are reviewed for reproducing
numbers, not for passing every gate: a pipeline that failed a
gate and shows the fix teaches more than one that never
measured anything.
