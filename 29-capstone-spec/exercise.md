# Exercise: Capstone spec: the pipeline and its gates, fixed in advance

A stakeholder asks to add a sixth gate: mean tokens at most 600. Argue both sides in writing, using Lesson 28's table: what assembly measured near that line, and what would the gate force the pipeline to become?

Work it with the lesson's code open beside you. Every number in the worked solution comes from running a variant of that code, and you should be able to reproduce each one.
