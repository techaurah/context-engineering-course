# Exercise: Filtering tool outputs: the cheapest tokens are the ones you never admit

The job changes: now the customer wants the cheapest in stock 40 litre compost that is also peat free. Which policy still finds the right row unchanged, which policy breaks because it dropped a needed field, and what is the new answer?

Work it with the lesson's code open beside you. Every number in the worked solution comes from running a variant of that code, and you should be able to reproduce each one.
