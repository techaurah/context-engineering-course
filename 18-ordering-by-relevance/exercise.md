# Exercise: Ordering: what the edges strategy actually buys, measured on all facts

Change the metric back to required facts only (Lesson 05 style) on the same 18 document contexts. Does edges win now? Explain the reversal in terms of whose facts the metric counts.

Work it with the lesson's code open beside you. Every number in the worked solution comes from running a variant of that code, and you should be able to reproduce each one.
