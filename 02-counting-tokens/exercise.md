# Exercise: Counting tokens: the approximation, and when it is good enough

Take the longest fixture document and compute its approx tokens, word count, and characters/4 by running the tokenizer on it directly. Which heuristic is closer for this document, and does that match the corpus-wide worst case?

Work it with the lesson's code open beside you. Every number in the worked solution comes from running a variant of that code, and you should be able to reproduce each one.
